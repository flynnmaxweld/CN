3. Fast 4-Minute Execution (No CLI Needed!)
  1. Connect Devices: Use Lightning Bolt (Auto cable): Connect DNS Server, Web Server, PC0 → Switch0 → Router Gig0/0. Connect DHCP Server, Laptop0 → Switch1 → Router Gig0/1.
  2. Router GUI Setup: Click Router0 → Config tab:
    • Gig0/0: Check [✓] On • IP: 192.168.10.1 • Mask: 255.255.255.0
    • Gig0/1: Check [✓] On • IP: 192.168.20.1 • Mask: 255.255.255.0
  3. Configure Servers:
    • DNS Server: Set IP 192.168.10.2, GW 192.168.10.1. Go to Services → DNS: Turn ON. Name: www.myweb.com, Address: 192.168.10.4 → click Add.
    • Web Server: Set IP 192.168.10.4, GW 192.168.10.1. Go to Services → HTTP: Ensure HTTP is ON.
    • DHCP Server: Set IP 192.168.20.2, GW 192.168.20.1. Go to Services → DHCP: Turn ON. Set Default GW: 192.168.20.1, DNS Server: 192.168.10.2, Start IP: 192.168.20.10 → click Save.
  4. Configure Clients:
    • PC0: IP 192.168.10.3, GW 192.168.10.1, DNS 192.168.10.2.
    • Laptop0: Open IP Configuration → click [●] DHCP radio button → verify "DHCP request successful!".
  5. Fast-Forward: Press Alt + D twice to turn all port lights green immediately.

6. Solved Viva Voce Questions (Pages 8–9 of Manual)
Viva Question Answer for Exam / Viva
1. Purpose of DNS server in a network? DNS (Domain Name System) translates human-readable domain names (e.g., www.myweb.com) into machine-readable IP addresses (e.g., 192.168.10.4), eliminating the need for users to remember numerical IPs.
2. Function of a DHCP server? DHCP (Dynamic Host Configuration Protocol) automatically assigns IP addresses, subnet masks, default gateways, and DNS server addresses to client devices dynamically, preventing manual IP configuration errors and IP conflicts.
3. Why is a router used in this experiment? To connect two different logical subnets/networks (192.168.10.0/24 and 192.168.20.0/24) and route packets between them at Network Layer 3. Without a router, devices in LAN 1 cannot communicate with LAN 2.
4. Difference between a Hub and a Switch? • Hub: Layer 1 device, broadcasts incoming data to all ports (creates single collision domain), half-duplex.
• Switch: Layer 2 device, uses MAC address table to forward frames directly to target port (separate collision domain per port), full-duplex.
5. Which protocol tests connectivity between devices and how? ICMP (Internet Control Message Protocol) using the ping utility. It sends an ICMP Echo Request packet to the destination device, and the destination responds with an ICMP Echo Reply.
