6. Solved Viva Voce Questions (Page 9 of Manual)
Viva Question Exact Answer for Staff
1. What is OSPF and why is it called a link-state routing protocol? OSPF (Open Shortest Path First) is an open-standard dynamic routing protocol. It is called a link-state protocol because every router maintains a map of the entire network topology by advertising the state of its directly connected links using Link State Advertisements (LSAs) and calculates shortest paths using Dijkstra’s SPF algorithm.
2. What is the purpose of the Router ID in OSPF? The Router ID is a unique 32-bit IPv4 address that uniquely identifies a router within an OSPF autonomous system. It is used during OSPF neighbor adjacency formation and the election of DR (Designated Router) and BDR (Backup Designated Router).
3. What does the wildcard mask represent in OSPF network command? The wildcard mask is the inverse of the subnet mask (e.g., 0.0.0.255 for 255.255.255.0). In OSPF, a 0 bit means "must match exactly", and a 1 (or 255) bit means "ignore". It tells the router which interfaces should participate in the OSPF process.
4. Which command is used to verify OSPF learned routes? show ip route ospf (or show ip route). OSPF routes appear prefixed with the letter O in the routing table.
5. Difference between static routing and OSPF routing? • Static Routing: Routes are configured manually by the administrator. Does not adapt automatically if a link fails; ideal for small, simple networks.
• OSPF Routing: Routes are discovered and updated dynamically. If a link fails, OSPF automatically recalculates an alternate shortest path within seconds.
