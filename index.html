EX 02 — SUBNETTING (30 MARKS)
1. AIM (2 MARKS)

To subnet a Class C network (192.168.10.0/24) using a /25 subnet mask (255.255.255.128), configure IP addresses on devices, and verify inter-subnet communication via a router in Cisco Packet Tracer.

2. PROCEDURE — NETWORK STRUCTURE (4 MARKS)

Hardware Required: 1 Router (Cisco 2911), 2 Switches (Cisco 2960), 2 PCs (PC0, PC1), Copper Straight-Through cables.
Interconnection: PC0 connected to Switch0 (Fa0/2). Switch0 connected to Router0 (Gig0/0). PC1 connected to Switch1 (Fa0/2). Switch1 connected to Router0 (Gig0/1).

3. PROCEDURE — IP ADDRESSING TABLE (6 MARKS)

4. PROCEDURE — NETWORK CONFIGURATION (7 MARKS)
