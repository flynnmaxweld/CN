6. Complete Viva Voce Questions & Answers (From Manual)
Viva Question Exact Answer to Tell Staff
1. What is Static Routing? Static routing is a technique where network paths are manually entered into the routing table by the network administrator using next-hop IP addresses or exit interfaces.
2. What are the advantages of Static Routing? • Very low CPU and RAM overhead on routers.
• No bandwidth wasted exchanging routing updates.
• Highly secure because only the administrator controls allowed network paths.
3. What is a Next-Hop IP address? The IP address of the neighboring router interface on the directly connected WAN link through which packets must be forwarded to reach the remote destination network. (For R0, next hop is 10.10.10.2).
4. What is the administrative distance (AD) of a Static Route? The default Administrative Distance of a static route is 1 (very high trustworthiness, second only to directly connected routes which have AD 0).
5. What is the main drawback of Static Routing? It cannot automatically adapt to network changes or link failures. If a link goes down, the administrator must manually reconfigure the route.
