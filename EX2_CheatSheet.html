2. Formula & Subnet Calculations ("Split at 128" Rule)

Subnet 1 (192.168.10.0 /25)

Network ID 192.168.10.0
Router Gateway 192.168.10.1 (First Usable IP)
PC0 IP Address 192.168.10.2 (Second Usable IP)
Broadcast ID 192.168.10.127
Subnet Mask 255.255.255.128

Subnet 2 (192.168.10.128 /25)

Network ID 192.168.10.128
Router Gateway 192.168.10.129 (128 + 1)
PC1 IP Address 192.168.10.130 (128 + 2)
Broadcast ID 192.168.10.255
Subnet Mask 255.255.255.128
3. Fast 3-Minute Execution (No CLI Needed!)
  1. Connect Devices: Click Lightning Bolt (Automatic Cable) → connect PC0 → Switch0 → Router0, and PC1 → Switch1 → Router0.
  2. Configure Router (GUI): Click Router0 → Config tab:
    • Gig0/0: Check [✓] Port Status: On • IP: 192.168.10.1 • Mask: 255.255.255.128
    • Gig0/1: Check [✓] Port Status: On • IP: 192.168.10.129 • Mask: 255.255.255.128
  3. Configure PCs: Click PC0 → Desktop → IP Configuration: IP 192.168.10.2, Mask 255.255.255.128, Gateway 192.168.10.1. Repeat on PC1: IP 192.168.10.130, Mask 255.255.255.128, Gateway 192.168.10.129.
  4. Instant Green Lights: Press Alt + D twice to fast-forward time (orange dots turn green immediately).
  5. Show "Successful" Result: Press P (Envelope tool) → click PC0 then click PC1. If status shows Failed (ARP learning), click PC0 → PC1 a second time → Successful ✓!
